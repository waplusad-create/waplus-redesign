WAPLUS 소스코드 카페24 적용용

카페24 적용을 위한
소스코드 복사 페이지

아래 순서대로 진행하면 와플러스 리디자인을 카페24에 바로 적용할 수 있습니다.

STEP 1

영상 파일 업로드

카페24 관리자 → 디자인 관리 → 파일 관리자에서 hero_bg_final.mp4를 업로드하고 URL을 복사합니다.

STEP 2

영상 경로 수정

아래 영상 경로 수정 섹션에서 업로드된 실제 URL로 교체합니다.

STEP 3

소스코드 전체 복사

아래 코드 블록의 [전체 복사] 버튼을 눌러 전체 HTML을 클립보드에 복사합니다.

STEP 4

카페24에 붙여넣기

카페24 스마트디자인 편집창에서 index.html을 열고, 기존 내용을 지운 뒤 붙여넣고 저장합니다.

영상 경로 수정 (필수)

REQUIRED

카페24 파일 관리자에 hero_bg_final.mp4를 업로드한 뒤, 아래 변경 후 코드의 URL 부분을 실제 업로드된 URL로 수정하여 소스코드에서 찾아 바꾸기 하세요.

▼ 변경 전 (현재 소스코드 내 코드)
<source src="hero_bg_final.mp4" type="video/mp4">
▼ 변경 후 (카페24 업로드 URL로 교체)
<source src="//waplus474.cafe24.com/web/upload/hero_bg_final.mp4" type="video/mp4">

※ waplus474.cafe24.com 부분은 실제 쇼핑몰 도메인으로 변경하세요. 파일 관리자에서 업로드 후 표시되는 정확한 URL을 사용하는 것을 권장합니다.
